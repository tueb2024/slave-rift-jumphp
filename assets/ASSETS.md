# Asset provenance

Slave Rift uses only assets that are either original project work or from sources with explicit reuse terms.

## Environment textures

- `textures/quadcompati/cop1_1.png`, `ceil1_1.png`, `crate0_side.png`: from LibreQuake / QuadCompati v0.01. The upstream README states that all texture WADs in v0.01 are under CC0 / MIT0 / BSD0.
- `textures/quadcompati/metal_panel.png`, `floor_dark.png`, `trim_grid.png`: project-made color/contrast derivatives of `cop1_1.png`, redistributed under the same permissive terms.
- `textures/rift-stone.png`: compatibility copy of `cop1_1.png` kept for the current world renderer.

Source: https://github.com/LibreQuake/QuadCompati

## Weapons

- `sprites/weapons/weapons.png`: original Slave Rift first-person sprite sheet (Colt .45 / Sten-style SMG / heavy machine gun), created for this project. CC0-1.0.
- `sprites/weapons/colt45.png`: earlier standalone version of the Colt sprite, kept for compatibility/history. CC0-1.0.

No VG Resource / Spriters Resource / Duke or other proprietary ripped artwork is included.

## Audio

- Gameplay SFX and drum voices are generated at runtime by `src/Audio/RiftSfx.php` as original 44.1 kHz PCM. They are project code/artwork under GPL-3.0-or-later; generated output may be reused as part of the game.
- The reactive lead and wave sting are generated by JumPHP `Synth` in `src/Audio/RiftMusic.php`.

## Geometry

- `maps/rift01.map`: original enclosed arena authored for Slave Rift using Quake `.map` syntax. GPL-3.0-or-later.
- Enemy, pickup and pulse meshes are original procedural geometry in `src/Gfx/Meshes.php`, GPL-3.0-or-later.

No asset is included merely because it was downloadable; every external source used here has explicit redistribution terms.
