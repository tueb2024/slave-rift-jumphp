# Asset provenance

All assets used by version 0.3 are original project work.

- `maps/rift01.map`: original box-brush arena, columns and four 0.18-unit steps. GPL-3.0-or-later.
- `textures/rift-stone.png`: original 64×64 pixel brick pattern authored procedurally for this project. CC0-1.0. You may redistribute, modify and use this image for any purpose without attribution.
- Enemy, pickup, pulse and weapon artwork: original procedural PHP geometry / drawing in `src/Gfx/Meshes.php` and `src/Scene/PlayScene.php`, under the project's GPL-3.0-or-later license.
- `thumbnail.svg`: original project preview, GPL-3.0-or-later.

Version 0.3 removes the previous Spirit-derived decorative brushes and the four QuadCompati PNGs. The upstream QuadCompati README grants CC0/MIT0/BSD0 terms to its v0.01 texture WADs, but the exact extraction history of the four existing PNGs was not recorded. An original replacement makes the provenance of every active asset explicit.

No ripped VG Resource / Spriters Resource assets, proprietary sprites, models, textures or audio are included. Being downloadable from a sprite archive is not itself a reuse license.
