# Slave Rift weapon sprites

`weapons.png` is the active 3-frame first-person sprite sheet: Colt .45, Sten-style SMG, then heavy machine gun / sulfateuse. Each frame is 256×160 with alpha.

The artwork is original project work created for Slave Rift and is released under CC0-1.0. It is not derived from proprietary game rips.

`colt45.png` is an earlier standalone export kept only for history/compatibility; the game now loads the sprite sheet to minimize assets and renderer changes.
