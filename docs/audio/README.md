# Sampled music demo

The 50-second WAV is generated by the
[branch's Survival checks workflow](https://github.com/tueb2024/slave-rift-jumphp/actions?query=branch%3Afeature%2F808-sampled-score).
Download the `sampled-music-demo-php-8.5` artifact and open
`slave-rift-music-demo.wav`. The WAV is included in that archive, not in the
source tree; local generation uses the commands below.

The WAV renders the actual PHP ProceduralScore events driven by RhythmClock,
seed 1337. XP stages advance every eight seconds: 1, 4, 8, 12, 16; pressure
increases at 36 seconds and boss percussion enters at 40. The final cadence at
48 seconds uses RiftMusic's resolution pitches. PCM is identical to the game;
the offline mixer applies the same 80 ms melodic voice release.

Reproduce from the repository root:

```sh
php tools/music-events.php > music-events.json
python tools/render_music_demo.py music-events.json
```

Python requires numpy. `analysis.json` records PCM peak, RMS and clipping.
The preparation sources used were FreePats commit
`426f32da700c42a4071b5061ee3bb2fc92de0680` and Fischer bank commit
`85fbecf1bec32553395625ea659e2a56dfd7c0e1`.
The WAV is a diagnostic arrangement, not a recording of live gameplay or a
subjective listening certification. It has no gameplay sound effects or browser
device latency. Melody naturally decays between events; bass samples last 1.35s,
longer than eight sixteenth notes at the starting 116 BPM (1.034s).

The previous session's WAVs and uncommitted source were not recoverable from
the available traces: no blob SHA was recorded. These assets were regenerated
from the originally specified sources, preserving the existing phrase grammar.
